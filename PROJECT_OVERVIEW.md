
# Project Overview

## Purpose

The C++ Console Quiz Game is an interactive quiz application developed to practise programming fundamentals and problem-solving.

## Quiz Categories

- Science
- Computer
- History
- Sports
- IQ

## Key Features

- Multiple difficulty levels
- Randomized questions
- Score tracking and high scores
- Save and resume functionality
- Lifelines
- File-based question banks

## Technologies

- C++
- File handling
- Functions and structures
- Arrays
- Random number generation

## Future Development

Possible improvements include expanding the question bank, improving score statistics, and adding automated tests.
