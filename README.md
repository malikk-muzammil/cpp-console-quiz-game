C++ Console Quiz Game

A console-based quiz game developed in **C++** as part of my Programming Fundamentals learning journey. The project combines multiple programming concepts into a single application, including file handling, structured programming, randomization, score management, and persistent game data.

The objective of this project was not only to create a quiz game but also to practice writing larger programs by organizing logic into reusable functions and managing different components of the application.

---

Features

* Multiple quiz categories
* Three difficulty levels
* Randomized question order
* Score calculation
* High score system
* Save and resume game progress
* Game activity logging
* Lifelines
* Time-based gameplay
* File-based question management

---

Technologies Used

* C++
* File Handling
* Structures
* Functions
* Arrays
* Random Number Generation
* Console Programming

Getting Started

Requirements

* C++ compiler (g++, MSVC, or MinGW)

Run

1. Clone the repository.

```bash
git clone https://github.com/malikk-muzammil/cpp-console-quiz-game.git
```

2. Open the project in your preferred IDE.

3. Compile `quiz.cpp`.

4. Run the executable.

---

Quiz Categories

* Science
* Computer
* Sports
* History
* IQ

Each category stores its questions in a separate text file, making it easy to update or expand the question database.
